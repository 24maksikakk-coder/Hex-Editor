#Репозиторий Hex Editor (побайтовое редактирование)
Описание
Hex Editor – это набор консольных утилит на 8 языках программирования для просмотра и редактирования бинарных файлов в шестнадцатеричном представлении. Программа позволяет открывать файлы, отображать их содержимое в виде HEX-дампов с соответствующими ASCII-символами, изменять отдельные байты, выполнять поиск и замену, а также вычислять контрольные суммы.

Проект создан как тестовый репозиторий для демонстрации реализации одной задачи на разных языках с использованием идиоматичных подходов и продвинутых возможностей.

Основные возможности
Просмотр файла – вывод HEX-дампера с адресами, шестнадцатеричными значениями и ASCII-представлением.

Редактирование – изменение байта по смещению (интерактивно или через аргументы командной строки).

Поиск – поиск байтовой последовательности или текстовой строки (с возможностью игнорирования регистра).

Замена – замена всех вхождений байтовой последовательности на другую.

Контрольные суммы – вычисление CRC32, MD5, SHA‑1 для открытого файла (опционально).

Работа с большими файлами – использование memory-mapped файлов (mmap) для эффективной работы с файлами любого размера.

Цветной вывод – подсветка адресов, HEX-байтов и ASCII-символов в терминале.

Сохранение изменений – запись изменённого содержимого обратно в файл или в новый файл.

Интерактивный режим – пошаговое редактирование с запросом смещения и нового значения.

Установка и запуск
Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения.

Язык	Установка	Запуск
Python	Python 3.8+	python hex_editor.py [опции]
JavaScript	Node.js 14+ и npm install commander chalk	node hex_editor.js [опции]
TypeScript	Node.js + npm install -g ts-node typescript и npm install commander chalk	ts-node hex_editor.ts [опции]
Go	Go 1.18+	go run hex_editor.go [опции]
Java	JDK 11+	javac HexEditor.java && java HexEditor [опции]
C#	.NET SDK 6.0+	dotnet run или csc
PHP	PHP 8.0+	php hex_editor.php [опции]
Ruby	Ruby 2.7+ и gem install colorize	ruby hex_editor.rb [опции]
Использование
text
hex_editor <файл> [команда] [опции]
Команды
Команда	Описание
view	Показать содержимое файла (по умолчанию).
edit	Редактировать байт по смещению.
find	Найти байтовую последовательность или текстовую строку.
replace	Заменить все вхождения одной последовательности на другую.
checksum	Вычислить контрольную сумму (CRC32, MD5, SHA1).
Опции
Опция	Описание
-o, --offset <смещение>	Смещение в байтах (для команд edit, find).
-b, --bytes <байты>	Байты для записи (в HEX, например FF 00 01) или строка для поиска.
-s, --string <строка>	Искать текстовую строку (для find).
--replace-with <байты>	Байты для замены (для replace).
--output <файл>	Сохранить результат в указанный файл (вместо перезаписи исходного).
--cols <число>	Количество байтов в строке дампа (по умолчанию 16).
-c, --checksum <тип>	Тип контрольной суммы: crc32, md5, sha1.
-h, --help	Показать справку.
Примеры
bash
# Просмотр файла
python hex_editor.py file.bin view

# Редактирование байта по смещению 0x10 на значение 0xFF
python hex_editor.py file.bin edit -o 16 -b FF

# Поиск текстовой строки "Hello"
python hex_editor.py file.bin find -s "Hello"

# Замена всех байт 00 на FF
python hex_editor.py file.bin replace -b "00" --replace-with "FF"

# Вычисление MD5
python hex_editor.py file.bin checksum -c md5
Особенности реализаций
Python – использует argparse, mmap для работы с большими файлами, цветной вывод через ANSI-коды.

JavaScript – использует commander, chalk, fs с потоками для больших файлов.

TypeScript – строгая типизация, декораторы для логирования.

Go – использует os, encoding/binary, flag, горутины для параллельных вычислений (контрольные суммы).

Java – использует NIO (FileChannel, MappedByteBuffer), java.util.zip.CRC32, MessageDigest.

C# – использует MemoryMappedFile, Span<byte>, System.Security.Cryptography.

PHP – использует fopen, fseek, hash для контрольных сумм.

Ruby – использует IO, StringIO, метапрограммирование для команд.
